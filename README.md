# SinCancer

Sitio estático inicial para un proyecto independiente de divulgación sobre el cáncer y transparencia de donaciones.

## Archivos

- `index.html`: página principal, información general, marcador de transparencia y controles para compartir.
- `styles.css`: diseño responsive.
- `script.js`: compartir/copia de enlace y preferencia local del aviso de cookies.
- `transparencia.html`: política inicial de transparencia.
- `privacidad.html` y `cookies.html`: borradores legales que deben revisarse y completarse.

## Antes de promocionar el sitio

1. Definir el porcentaje y la base exacta de cálculo de las donaciones.
2. Elegir la entidad beneficiaria y publicar justificantes cuando haya aportaciones reales.
3. Completar la identificación y el contacto del titular en la información legal.
4. Elegir proveedor publicitario y revisar sus políticas, el consentimiento requerido y la configuración de anuncios.
5. Conectar analítica solo si es necesaria y con la configuración de privacidad apropiada.
6. Añadir un sitemap.xml cuando se conozca la URL pública definitiva.

La web no carga actualmente scripts publicitarios ni analítica y no muestra métricas ficticias. Las cifras aparecen como pendientes hasta que haya datos verificables.
